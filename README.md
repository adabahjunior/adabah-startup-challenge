# THE ADABAH STARTUP CHALLENGE 2026

> **Build. Pitch. Grow.**
> A 3-week startup mentorship and pitch competition designed to help student entrepreneurs turn their ideas and businesses into stronger, more investable ventures.

---

## 🌟 Key Features

- **Default Light Theme & Dark Theme Toggle**: Warm sand / ivory linen palette with rich cocoa accents, plus one-click dark mode toggle with persistent preferences.
- **Flawless Mobile View**: 100% responsive, optimized for all screen sizes down to 320px with zero horizontal scroll.
- **5-Step Application Wizard**: Multi-step application portal (`/apply`) and homepage modal with live validation, character counting, and draft auto-saving.
- **Supabase Integration**: Live database sync with fallback to local JSON storage.
- **Real-Time Application Tracker**: Founders can track their application review status by Application Reference ID or email.
- **Reviewer Portal**: Interactive dashboard for reviewing applications, filtering by track, updating status, and exporting CSV.
- **Submission Receipts**: Print-ready submission receipts with QR code and application details.

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and fill in your Supabase credentials:
```bash
cp .env.example .env
```

### 3. Run Locally
```bash
node server.js
```
The server will start at `http://localhost:3000`.

- **Homepage**: `http://localhost:3000/`
- **Application Portal**: `http://localhost:3000/apply`
- **API Status**: `http://localhost:3000/api/supabase-status`
